# 红书发帖与文字分页（2026-09-20）

## 现有实现与本次变更

- `forum_compose_page.dart`：复用现有创建/回复、统一账号、附件上传、可见范围与文章富文本编辑；增加持久化草稿、预览、多选照片、拍照、排序及图片查看。发布、照片、文字图片入口为原标签字号的1.5倍，采用柔和红色。
- `forum_card_editor.dart`：独立文字图片编辑器，保留正文，不修改笔记数据。纯文字、基础、光影、简约、涂鸦、涂写均为本项目绘制的简单模板；原代码实际上只有单色封面，没有这些模板。
- `forum_card_layout.dart`：360×480逻辑尺寸，导出1080×1440 PNG。字号16–60，默认20，系统/思源黑体，行距、字距、16–40边距和左/中/右对齐。预设11种背景以及HSV/HEX自定义颜色；自定义文字对比不足时自动回退至黑或白，正文对比度至少4.5。装饰不覆盖文字区。
- 原封面接口 `forum_text_image.dart` 保留兼容入口；新发帖流程使用所有分页图片，不截断正文，不自动缩字号。
- `forum_draft_store.dart`：复用账号隔离的本地SQLite缓存，图片复制到应用支持目录。保存文字、标题、富文本、标签、可见范围、附件顺序、样式、手动分页符、请求编号。退出及进入后台时保存；不删除原文件。成功发布的草稿归档，不作为未发布草稿恢复。
- `forum_edit_page.dart`：原作者编辑接口038继续使用原post_id；新增编辑草稿自动保存与云端版本冲突提示。修改先进入已有本地待同步队列，支持手动重试。详情显示“已编辑”。

## 分页规则

使用TextPainter的实际高度测量；先优先段落边界，再句子标点，最后在完整字符/英文单词边界分页。每页相同尺寸、字号、样式。手动分页符为form feed（U+000C），仅用于文字图片源稿，不发送至正文。样式改变会重排所有页；可点击缩略图查看各页。

极端长的单个英文词在整页仍容纳不了时会提示调整字号/空间，不强行截断。后台单帖最多512个附件、每个10MB，正文继续沿用20000字限制；超出时提示拆分发布，不静默丢弃页面。
