# 后台殊胜日更新

## 一次性启用

1. Supabase SQL Editor 执行 `202609180027_calendar_observances.sql`。依赖已执行 023；增加数据格式约束，不删除或改写已有内容。
2. 使用此次更新的管理端，进入「藏历 → 管理殊胜日」。沿用现有 admin-api 的 links.get / links.save，无需修改 Edge Function。
3. 编辑并保存发布。管理端与包含动态殊胜日功能的手机客户端需各更新一次；以后同结构内容调整无需重发 APK。

## 可编辑项

- 栏目标题、中英文说明。
- 新增、编辑、停用条目；最多500条。
- 藏历月份（0为每月）、开始日/结束日、中英文名称。
- 来源名称、HTTPS链接。
- 是否包含闰月；重日两天/第一天/第二天。
- 空列表表示全部撤下，不会恢复内置默认值。

## 更新机制

复用 app_links.calendar_traditions.observances，保存版本号与管理员审计沿用已有后台机制。理发/洗头编辑保存时保留殊胜日字段；殊胜日编辑保存时保留理发/洗头字段。并发修改拒绝旧版本，防止相互覆盖。

手机启动、恢复前台、打开藏历及前台每5分钟刷新。页面监听配置更新；有效内容缓存离线使用。无远程配置时使用内置31条；格式异常拒绝更新并保留上次有效配置。后台内容只作为数据解析，不执行代码。

日期换算仍使用已有2025–2026离线数据；延长历表年份、增加新算法或新交互不属于本次远程内容更新范围。
