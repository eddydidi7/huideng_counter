# 首页法语寄语

本次代码新增后台内容读取及 SQLite 缓存，保留 APP 标题、今日念诵和计数项目。首页显示三行摘要，点“查看全文”可阅读完整内容和出处。

## 后台准备（尚未在云端执行）

在测试项目 Supabase SQL Editor 执行 `supabase/migrations/202609150002_home_messages.sql` 一次。这是新增公共内容表，不改用户计数表。成功后进入 Table Editor → home_messages，编辑唯一的 home 行：

| 字段 | 用途 |
| --- | --- |
| body_zh | 中文法语寄语 |
| body_en | 对应英文译文 |
| source_zh | 中文出处或署名，可留空 |
| source_en | 英文出处或署名，可留空 |
| is_published | 两种语言填好后开启发布；关闭表示下架 |

管理员通过 Supabase 控制台修改和保存，无需在 APP 放置管理员密钥。用户不论是否登录，都只能读取已发布的这一条公共内容，无权新增、编辑或删除。私人计数数据仍按账号隔离。

## 更新行为

APP 启动、返回前台和前台每五分钟检查更新；离线保留上次成功获取的寄语。联网读到下架或空结果后清除缓存、显示原默认文案。离线设备无法立即获知下架。

内容缓存单独保存在 public_content.sqlite，不加入用户同步队列，不改计数 SQLite 表结构。未配置新表、请求失败或缓存异常均不阻止计数。

本次没有代写或冒用任何上师的开示，请管理员填写确认过出处和译文的内容。首次发布需要执行上述 SQL、填写内容，并安装包含本次改动的新 APK；之后仅修改后台句子即可，不必重新发包。
