# 结缘板块（2026-09-20）

## 已实现
- 在原红书板块中加入结缘，复用 forum_posts、图片上传、评论、点赞、收藏、搜索、作者编辑和分享。
- 类型：免费、有偿、求结缘。物品名称、说明、数量、新旧、价格/币种、国家/大致地区、交付和邮费；不收集公开家庭地址或必填电话。
- 可结缘 / 已预留 / 已结缘。编辑沿用原记录及版本冲突校验，修改本地保存并可重试云同步。
- 我要结缘在服务端重新核对状态，打开作者私聊并附入现有帖子卡片草稿，由用户发送。聊天隐私/好友限制继续有效；已结缘禁用新咨询入口。
- 全部 / 免费 / 有偿 / 求结缘筛选，沿用最新排序。个人主页 → 我的结缘：我发布的、我收藏的、已结缘。
- 新字段进入本地发帖/编辑草稿，不清空旧草稿或帖子。图片沿用压缩上传、缓存及列表缩略显示。
- Windows 后台 → 结缘管理：总开关、各类型、图片开关、资源图片总开关、规则、币种和每个等级的权限/额度；用户等级分配；举报、下架、软删除、警告、限制发布、封禁。
- 当前项目没有现成完整的 Lv.1～Lv.5 权限服务，因此新增 app_user_levels 作为等级配置，仍关联原 auth.users，不建立第二套账号。资源图片总开关在本轮控制结缘图片，不声称已接管其他模块全部资源配额。
