# 收藏2、通知入口、藏历字号及计数震动

## 本次修改
- 笔记增加独立 `isFavorite2`、收藏2列表及加入/取消操作，保留原收藏。普通与超长笔记编辑入口均支持。
- 本地数据库升级到 v8，旧笔记默认未加入收藏2；离线操作保存在本地并进入原同步队列。
- 常用入口改为“通知 / Notifications”，进入已有通知页。
- 藏历日期按原字号乘 1.5，通常为 16 → 24；月份导航适配 320px 小屏。
- 屏幕和两种音量键沿用统一计数入口，在本地写入成功后触发短促震动。关闭计数震动不影响计数。

## Supabase 步骤
在 SQL Editor 中执行 `supabase/migrations/202609200051_notes_favorite2.sql`。它为现有 JSON 笔记数据增加字段兼容保护，避免旧客户端同步时丢失收藏2标记；不删除笔记、不重建笔记表、不批量重写正文。
本次不需要更新 Edge Function。
