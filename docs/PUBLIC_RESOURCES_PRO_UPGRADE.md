# Pro 网盘大文件升级（048）

## 当前结论

用户已升级 Pro。代码适配单文件最多 512 MiB，可容纳约 300 MB 的 APK；尚未在该项目线上验证设置、部署或真实手机上传。047 已执行，无需重跑或清空数据。

Pro 不会自动修改已有代码、数据库约束、桶限制或应用配额。需要以下步骤全部完成。

## 部署顺序

1. Supabase → Storage → Settings：将 **Global file size limit** 调整到至少 536870912 字节（512 MiB）。如果界面使用 GB，可设置 1 GB；本应用仍限制每文件 512 MiB。
2. SQL Editor 执行 `supabase/migrations/202609200048_public_resources_large_files.sql`。
   - 把公共网盘的大小约束与桶上限提高到 512 MiB。
   - 默认 20 MiB 的应用单文件限额升级为 512 MiB；每日默认上传 100 MiB 升为 1 GiB、下载签发 500 MiB 升为 2 GiB。
   - 已自定义的应用限额、总容量和开关保留。共享总容量仍是原值（原默认 1 GiB），可随后在后台调整。
   - 增加上传凭证期限及分段校验状态，不删除帖子、用户或文件。SQL 会替换两个旧大小约束，Dashboard 可能因此提示结构变更。
3. 更新 Edge Function **public-resources**：使用 `docs/deployment/public-resources-dashboard.ts` 全部内容替换 index.ts，部署。Verify JWT with legacy secret 保持关闭；函数内部校验身份、短期上传凭证和数据库权限。
4. 更新包含本次代码的 Android 客户端及 Windows 后台。旧 APK 只有小文件上传方式，不能仅凭 Pro 升级上传 300 MB。此次任务没有生成 APK。
5. 如尚未部署 047 对应 admin-api，请使用 `huideng_admin/supabase/dashboard-admin-api.ts` 全部代码更新；本次无需另增 admin-api action。
6. 用真实 300 MB APK 实测：上传→中断网络→恢复重试→校验→公开→另一正式账号下载→校验一致→系统安装界面。安装仍需用户确认，同包名/同证书才能覆盖更新。

## 上传及校验

采用 Supabase TUS：文件以 6 MiB 块直接上传到私有 Storage，不经过 Edge 整包转发。上传 URL 保存在设备本地，重试通过 HEAD 获取已接收字节偏移；不把服务端密钥交给客户端，也不保存上传 token。

完成后，Edge 每次读取并验证 8 MiB，SHA-256 中间状态只保存在服务端表中；最后完整摘要一致才公开。这样不会将整个 300 MB/512 MiB APK 放进 Edge 内存，也不会把全部哈希工作挤在一次请求内。应用进度最后 10% 为完整性校验。校验失败不公开，失败任务保留供重试/管理员处理。

上传令牌只授权一个随机对象路径，禁止覆盖。旧版小文件 HMAC 上传仍兼容；旧客户端上传超 50 MiB 会提示更新客户端。

## 开关、删除与费用边界

- 关闭上传立即停止新授权与发布，但之前已签发的 Storage 上传授权可能仍完成字节传输；这些文件不会绕过公开校验。
- 删除立即从 App 列表隐藏并停止签发新下载链接。为防止有效上传凭证在删除后再次写回对象，清理最迟需等待授权起算 26 小时，之后刷新后台继续物理删除并释放占用量。未实现定时清理任务。
- 下载链接有效期 2 分钟。每日下载额度按签发次数计，不等于云厂商流量硬封顶；同一有效链接可能被重复使用。
- 应用总容量是已登记文件配额，不是 Supabase 账单上限。直接上传在校验前可能暂占额外空间；仍需查看项目实际 Storage 用量和费用。
- 本轮只升级公共网盘，不放大聊天附件等其他模块的限制。APK 通过已有文件卡片识别和安装流程处理。
- 现有 Android 安装器的独立 APK 校验上限为 500 MiB，本轮保留；300 MB APK 在该范围内。网盘 512 MiB 是文件存储上限，不能理解为所有大小的 APK 都可安装。
- 当前网盘仍要求正式账号登录；不自动开放无登录的永久 APK 下载网址。

- 4 项 Edge 测试通过，其中使用超过 300 MiB 的数据对照 Node SHA-256，验证跨请求保存并恢复哈希状态。
- 047+048 数据库测试通过：重复执行、300 MiB 元数据、逐段校验、禁止提前公开、保持已有开关/自定义总容量，以及上传凭证有效期间延迟物理删除。

- 以上为本地模拟/协议测试，不代表已在用户 Pro 项目实际上传 300 MB APK；仍需部署后进行手机验收。
