# 笔记导出、聊天个人号与群容量

## 功能
- 笔记编辑页 → 更多 → 导出 TXT / PDF / Markdown，保存的是当前编辑内容（包括尚未自动保存的内容）。取消系统保存窗口不写出文件。
- TXT 为UTF-8纯文本，图片使用“[图片]”标记。Markdown 保留标题、粗体、斜体、删除线、链接、列表和内嵌图片；阅读器需支持 data URI 才能显示内嵌图片。
- PDF 离线分页渲染正文及内嵌图片，使用设备字体，不联网下载字体。当前为图片式PDF，文字不可选中复制；不保留所有富文本样式。
- 每个聊天身份自动分配唯一数字个人号（10000001起）；已有身份迁移时补号，新身份插入时自动生成。昵称修改不影响号码，数据库触发器禁止修改号码。个人资料显示号码，可按号码添加好友。
- 首次联网创建聊天身份才取得号码；离线安装不产生服务器号码。访客卸载/清除数据可能失去原身份；同一账号多设备共用同一个号。游客转正式账号需保留同一auth.uid。
- 群成员上限默认0（不限）。并非无限性能承诺，服务吞吐与资源仍有实际限制。Windows后台 → 群聊管理，可逐群设限、分页查看成员并确认移除。降低上限只限制新成员，不自动移除任何人。群主不能从此入口移除。
