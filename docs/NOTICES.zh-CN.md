# 发布通知和法语句子

## 入口
底部导航保持：计数、藏历、论坛、我的。“我的”顶部新增通知区域，约占页面可用高度的五分之二，可独立滚动并点击“查看全部”。下面保留原账号同步、登录、退出登录、密码、备份与设置功能。

## Supabase 操作
1. 打开测试项目 Table Editor，选择 public.app_notices。
2. Insert → Insert row，填写 title_zh（中文标题）、body_zh（中文正文）、title_en（英文标题）、body_en（英文正文）。句子也作为一条通知填写。
3. is_published 保持 false 即为草稿；两种语言填写完成后设为 true 并保存即可发布。
4. is_pinned=true 为置顶；published_at 为排序使用的发布时间，默认当前时间。不是定时发布功能，设未来时间不会延迟公开。
5. 修改原行可更新通知；is_published 改回 false 可撤下。断网设备要等下次成功刷新才会移除旧缓存。

APP 点击通知、返回前台、前台每五分钟或下拉刷新都会尝试更新。当前展示按置顶、发布时间排列的前 100 条；正文点击可完整阅读，支持中英文。离线显示本地 SQLite 缓存。

这是公开的 APP 内通知，所有用户包括未登录用户可阅读已发布内容。不要在正文中填写个人隐私。普通用户无写权限，也看不到未发布草稿。个人计数数据权限不变。

本阶段为文字通知，不含系统推送、图片附件或定时发布。手机需覆盖安装新版 APK，Windows/iOS 需分别编译实测。
