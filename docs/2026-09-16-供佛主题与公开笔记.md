# 供佛、颜色偏好、关于与联系、后台发布笔记（2026-09-16）

用户端 1.0.9（10），Windows 后台 0.1.2（3）。

## 操作
- 管理端「系统设置」填写供佛 HTTPS 网址，可留空。用户端「我的」顶部显示供佛，位于论坛上方。
- 用户端「设置 → 颜色偏好」选择跟随系统、黑色或白色，保存到本地。
- 管理端「关于与联系」编辑中英文介绍、邮箱、QQ、最多 8 张图片。支持公开 HTTPS 图片地址、电脑 PNG/JPEG/WebP 图片（每张 2 MB）。上传后为公开资源，保存并发布后显示。
- 管理端「后台发布笔记」新建、编辑、撤下公开正文。最多 100 篇，每篇 10000 字符，总大小 1.2 MB。
- 用户端「笔记 → 左上角菜单 → 后台发布」单独查看；底部五个导航保留。私人笔记及同步队列不受影响。
- 发布内容联网启动、回前台、前台每 5 分钟或手动刷新时更新；离线显示缓存，图片需要网络。
- 并发版本冲突会拒绝旧版本保存，刷新后重新编辑。
