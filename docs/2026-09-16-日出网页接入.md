# 日出网页接入（1.0.4+5）

根据用户要求，用现成网站查询日出与太阳正午，不再等待和风天气账号。

- 查询入口：https://www.timeanddate.com/sun/
- 官方说明：https://www.timeanddate.com/sun/help
- 浏览器已验证城市搜索入口及北京城市页：包含 Sunrise、Civil Twilight、Solar Noon，当地时间和月份年份选择。
- 点击底部「日出」直接使用 url_launcher 的 inAppBrowserView 打开；不支持的平台由插件降级，启动失败再尝试 externalApplication。返回 App 有中文字段说明、重新打开、系统浏览器入口和可复制网址。
- 此方式是系统提供的应用内浏览窗口，不是常驻底部导航中的 Flutter WebView。第三方网站包含英文及日落等额外内容，没有抓取或改写网页。
- 尚无 App 自动定位、离线缓存或日中提醒。中国大陆不同网络的可达性尚未验证。
