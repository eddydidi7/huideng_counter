## 数据与安全

SQLite 未改表、未升级版本。论坛文字缓存复用 public_content.sqlite 的 content 表，cacheKey 为 forum_feed，与私人计数和笔记队列分开。

Supabase 迁移尚未执行。拟新增 forum_categories、forum_posts、forum_feed_v1，迁移没有删除或覆盖旧表的语句。如果已有同名表，CREATE TABLE 会失败，事务回滚；必须先检查现有结构，再选择增量适配，不能删表重建。

RLS 只公开已发布且未软删除、分类启用的帖子。游客和普通登录用户无写权限；本阶段没有发帖入口，避免未经验证的游客写入权限。RPC 使用 security invoker，权限仍受 RLS 限制。没有新 Edge Function，没有新 API Key，没有客户端高权限密钥。

Dashboard 待办：检查同名表/函数是否存在；在测试项目执行并登记 202609170009 迁移；验证 anon 和 authenticated 的真实 RPC。切勿把本地测试通过等同线上部署成功。
