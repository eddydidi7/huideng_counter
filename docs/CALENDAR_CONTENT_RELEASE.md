# 藏历内容后台编辑

## 入口与范围
Windows 管理后台 → 藏历（超级管理员）。可修改展开标题、30天理发/洗头中英文内容、年度说明、婴儿说明、特殊日期提醒、附注与咒语、资料来源。保存并发布后，当天提示和完整表共用同一份内容；藏历换算与特殊日期规则不变。

## 部署
1. Supabase SQL Editor 执行 `supabase/migrations/202609180023_calendar_traditions.sql`。依赖现有后台005、007、008迁移。缺少依赖时整个事务回滚，不会部分发布；请勿盲目重跑旧迁移。
2. 使用包含本次改动的 Windows 后台和手机版。此次没有构建 APK。已经安装的旧版手机如没有读取该字段，需要先更新一次 APK；更新后文案修改无需再换 APK。
3. 后台“藏历”编辑，点击“保存并发布”。沿用 admin-api 的 links.get / links.save，无需新增 Edge Function。

配置保存在 `public.app_links.calendar_traditions`，空对象使用内置默认。手机启动/恢复前台或前台每5分钟刷新，联网失败保留缓存。超级管理员权限、乐观版本校验、审计沿用现有系统。普通用户只能读取。迁移新增字段/校验并扩展发布函数，不删除用户数据。
