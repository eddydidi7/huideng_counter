# 论坛整理记录（1.0.24+25）

## 本次实现

- 首页：论坛标题、一个搜索框、最新／热门／板块、卡片流、右下角加号发帖。
- 个人菜单移到右上角：我的帖子、我的回复、我的收藏、原论坛。没有删除原论坛入口。
- 四个板块：学修交流、共修活动、资料分享、建议反馈。板块页显示说明、服务端帖子数量和最新帖标题，点击进入独立列表。
- 旧 questions／experience 分类在读取时映射至 study；不改旧帖、不删分类、不迁移原有数据。
- 帖子卡片保留图片、标题、摘要、作者、时间、板块、点赞／回复数。
- 详情增加作者头像（无头像用默认图标）、板块、附件、固定回复／点赞／收藏／分享。Android 使用已有系统文字分享通道；其他平台暂复制帖子文字供粘贴，不生成不可用的网页链接。
- 发帖表单为板块、标题、正文、可选图片／附件。昵称后台自动读取现有聊天共用昵称，取消重复昵称输入区；不要求标签。
- 图片和文件：每帖最多 9 个，单个源文件不超过 10MB；图片复用现有压缩器。小文件上传成功后在一个数据库事务中关联帖子和附件。
- 上传失败保留页面内容；同一 UUID 提交重试幂等。退出未发布页面仍确认丢弃；不会删除任何已存在的用户内容。
- 搜索涵盖标题、正文、作者及附件文件名。搜索词通过参数传入，按字面子串匹配。
- 热门 = (点赞×3 + 回复×5) / sqrt(1 + 最近活动距今天数)，置顶优先、发布时间／UUID 打破并列；尚未采集浏览量，没有虚构浏览量。

## 新增云端配置：016

文件：supabase/migrations/202609170016_forum_layout.sql，依赖原 009／010／011。

- 新表 forum_attachments：UUID、post_id、owner_id、path、name、kind、size、created_at。
- 新私有 Storage 桶 forum-files，单文件 10MB。此限制与未来共享文件的 100MB 目标无关。
- 新 RPC：forum_feed_v2、forum_sections_v1、forum_action_v2；增加只读分类映射函数 forum_section。
- 旧接口仍保留，旧客户端及 Windows 管理端原有接口不替换。
- 新接口沿用已有 Auth 和论坛账号限制、发布限频及回复锁定规则。未新增注册系统。
- 附件表客户端只读，写入由发布 RPC 完成；附件路径校验账号和帖子 UUID，大小以 Storage 对象元数据为准。
- Storage 上传只能写自己 UUID 目录，客户端没有新增更新或删除权限。未发布文件仅上传者可读；公开已发布帖附件可读；隐藏帖子后新的附件访问授权被拒绝。
- 已签发下载链接在有效期内仍可访问（图片链接最多一小时、点击下载新链接五分钟）。不是立即撤销已签发链接。
- 本次无新增 Realtime 配置、API Key、Flutter package、SQLite 表或迁移。不影响计数、笔记、聊天数据。
