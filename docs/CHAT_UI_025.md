# 聊天体验整理（1.0.25+26）

## 本次修改

- 底部顺序保持计数／藏历／聊天／笔记／我的。NavigationBar 内容高度从默认 80 调为 73.6（缩小 8%），图标仍为 21.6；系统安全区不压缩。
- 聊天首页顶部只显示聊天、搜索和加号；加号保留发起聊天／添加好友／建群，增加通讯录／好友请求和共用昵称设置。没有删除昵称记忆或通讯录。
- 排序增加未读优先：置顶、未读、其余，再按当前服务端会话更新时间倒序。手动标记未读同样参与排序。现有服务端 updated_at 也可能由群名修改更新，并非独立的最后消息时间字段。
- 长按会话增加清空本机记录。详情更多菜单增加同一操作、恢复显示历史、删除本机会话、拉黑／解除拉黑。
- 清空必须确认；只保存当前已加载历史的显示截止时间，保留云端／对方内容、本地缓存、草稿、待发送队列和下载文件。恢复入口撤销这个显示标记。本功能不是删除 Supabase 消息或擦除本地文件。
- 收到较新的消息照常显示，旧历史重新拉取也不会重新显示，除非用户选择恢复。
- 修复退出群聊成功后，返回逻辑走统一草稿保存流程。
