# 聊天输入栏与一对一视频通话（2026-09-18）

## 客户端
- 紧凑输入栏：左侧语音 34 像素图标、48 像素点击区，中间文字/按住说话，右侧表情与附件；有文字时显示发送。
- 附件四列：相册、拍照、视频通话、位置、文件、音乐、语音输入、语音通话、在线直传；保留现有文件大小限制。
- 聊天信息：成员/邀请、群二维码、搜索、免打扰、置顶、本机提醒、背景色、清空/恢复本机显示、收到的文件、投诉及原有管理操作。
- 搜索目前针对已加载的记录；加载更早记录后可扩大搜索范围。
- 位置发送前确认，仅发送一次坐标与地图链接，不追踪位置。
- Android 语音输入调用系统识别界面；无系统识别服务时可使用输入法麦克风，结果先进入草稿。
- 提醒依赖系统通知授权与电量策略，可能延迟。

## 视频通话
沿用 WebRTC、chat_call_v1、既有隐私/黑名单/设备占用规则；新增 media_type=audio/video，旧请求默认 audio。接听后才开启接听方摄像头。支持本地预览、远端画面、静音、扬声器、关闭/开启视频轨道、切换摄像头、拒接和挂断。进入后台暂停视频轨道，回到前台按用户开关恢复；挂断停止并释放音视频轨道。按网络情况限制视频码率。

仅一对一前台通话；不是系统级后台来电服务。双方需安装包含视频能力的新客户端。无 TURN 时部分网络无法直连，不能保证公网接通。现有 voice-config 可提供 TURN，不将永久中继密码放入 APK。尚未完成双机真机和不同网络测试。
