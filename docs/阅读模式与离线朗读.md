# 笔记阅读模式与离线朗读（1.0.44）

入口：打开笔记 → 顶栏阅读图标，或更多 → 阅读模式。

- 正文使用只读快照，无笔记写入接口；进入前仅完成编辑页已有的本地保存。
- 轻触正文显示/隐藏控制栏。支持12–40字号、系统/思源黑体、行距、字距、夜间/纸张/明亮主题。
- Android 亮度只调整本 App 窗口，退出阅读或进入后台恢复原窗口亮度。
- 播放/暂停/继续、停止、上下段、0.5–2.0语速、自动/中文/英文。
- “重复本文”默认关闭；开启后全文朗读完从头循环，停止后立即结束本次朗读。
- 使用系统 TTS，只选择无需网络的音色。手机须安装对应中文/英文离线语音包。提供系统设置和安装入口；语音包由手机语音引擎下载。
- 不同引擎的文字定位回调不同：有回调时从当前位置继续，无回调时从当前文本片段开头继续。
- 阅读与朗读位置分别保存；朗读时高亮当前段落，不强制移动阅读位置。“从当前阅读处朗读”可主动对齐。
- 阅读偏好与进度按账号、本地 noteId 隔离，存在独立 SharedPreferences 键中，不修改 notes 表，不新增云端表。本版不跨设备同步阅读进度。
- 阅读位置以段落文本锚点和段内比例恢复；锚点被正文修改破坏时，退回附近段落。
- 内嵌图片可离线显示；远程图片未缓存时提示联网，不修改原图片引用。
- 防误编辑默认开启，正文始终只读，修改需返回原编辑页。

无需执行新的 Supabase SQL。既有038/040功能随客户端一并包含，仍使用原数据库接口。

字体：Adobe Source Han Sans，按 SIL OFL 1.1 分发，许可证随 assets/fonts/LICENSE.txt 打包。
